# Free PDF Editor

A free, native PDF editor for Mac and Linux that edits the existing text inside a PDF, in the font already embedded in it, and saves everything you didn't touch byte for byte.

**Download:** [getfreepdfeditor.com](https://getfreepdfeditor.com/#download) · or the files of the [latest release](https://github.com/HeroPD/free_pdf_editor/releases/latest)

- **macOS** 11 or later (Apple silicon and Intel): `Free-PDF-Editor.dmg`
- **Windows**: coming soon.
- **Linux** x86_64: `Free-PDF-Editor.AppImage` (make it executable, then run it)

The app updates itself: updates come from the releases here, and each is signed; the app installs only updates signed by us.

## What it does

Edit text in place in the PDF's own fonts; find and replace; reorder, rotate, insert, extract and export pages; add and replace images; fill in forms; sign; highlight, notes and freehand drawing; password protection (AES-256); print. It works offline and your files never leave your computer.
